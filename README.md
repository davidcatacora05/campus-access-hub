# Campus Access Hub

Build me an application that has a student ID that is able to tap in using the NFC reader on the phone. Let it know if students are denied access, let them know why like "After hours" or "No access" and if accepted, it'll record what time tapped in and who tapped in. Also, there will be a facility operations supervisor that has a dashboard and can see the occupancy and when it's limit is close. Students can also see when a building is near capacity. At the bottom, there will be a menu of classes, calendar, notifications, and student ID. The application will be called Campus
